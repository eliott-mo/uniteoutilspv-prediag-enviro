# Community Cloud pour les apps du parc. Roues uniquement : le Cloud n'a ni
# compilateur ni GDAL système.
#
# POURQUOI FIGER. Sans plafond, le Cloud installe les dernières versions et les
# majeures sautent (pandas 2.x → 3.x). L'installation réussit mais l'app peut

# déployée alors qu'elle dysfonctionne.
#
# ATTENTION GEOPANDAS. geopandas tire pyogrio et pyproj, qui embarquent GDAL et
# PROJ dans leurs roues. Ne jamais les dé-épingler sans vérifier que les roues
# manylinux existent pour la version de Python choisie dans les réglages de
# l'app (share.streamlit.io) — le .python-version du dépôt n'est pas lu.
#
# TESSERACT n'est pas un paquet Python : il est déclaré dans packages.txt.
# pytesseract n'est qu'un appel au binaire ; sans lui, les captures d'écran ne
# sont pas lues et l'app le dit, elle ne plante pas.
#
# RÉGÉNÉRER (après toute modification de directes.txt) :
#
#   python -m pip install --dry-run --ignore-installed --only-binary=:all: \
#     --python-version 3.14 --implementation cp --abi cp314 \
#     --platform manylinux_2_17_x86_64 --platform manylinux_2_28_x86_64 \
#     --report r.json -r directes.txt
#
# puis reporter ici les couples nom==version du champ "install" de r.json.
